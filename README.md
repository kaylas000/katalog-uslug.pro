# katalog-uslug.pro

Каталог профессиональных услуг (статический сайт, GitHub Pages).

## Шапка и подвал на всех страницах

Один источник правды: `partials/site-header.html` и `partials/site-footer.html`. После правок запускайте:

```bash
npm run build:layout
```

Скрипт обрабатывает **все `*.html` в корне** репозитория.

### Новая страница без «каркаса» шапки/подвала

1. Скопируйте файл **`templates/page-blank.html`** в корень под нужным именем, например `usluga-nazvanie.html`.
2. В `<head>` поменяйте `<title>`.
3. **Меняйте только HTML между** `<!-- katalog:page-main -->` и `<!-- katalog:page-main-end -->` — это весь контент страницы.
4. Не удаляйте маркеры (они остаются в файле — по ним скрипт находит ваш контент при каждой сборке).
5. После `<!-- katalog:page-main-end -->` до `</body>` оставьте блок с `<script src="js/main.js?...">` как в шаблоне (при необходимости добавьте свои скрипты ниже).
6. Выполните `npm run build:layout` — подставятся актуальная шапка, мобильное меню, подвал и виджет консультанта из partials.

Готовые страницы без этих маркеров по-прежнему обновляются старым алгоритмом (полная замена блока от шапки до подвала).
