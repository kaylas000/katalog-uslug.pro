================================================================================
  ЧТО СДЕЛАТЬ (по шагам, без путей в Cursor)
================================================================================

1) Открой папку проекта в ПРОВОДНИКЕ Windows — ту, где лежит README.md
   и папка "worker". Имя папки: katalog-uslug.pro

2) Найди ЭТОТ файл: neon.local.example.txt
   Правый клик по нему → Копировать.
   Правый клик по пустому месту в той же папке → Вставить.
   Появится копия. Переименуй копию в ТОЧНО такое имя:

        neon.local.txt

3) Открой neon.local.txt в Блокноте.
   Выдели всё (Ctrl+A) → Удали.
   Вставь ОДНУ длинную строку из Neon — Connection string
   (она начинается с postgresql:// или postgres://)
   Сохрани файл (Ctrl+S).

4) Открой Cursor, меню Terminal → New Terminal.
   Внизу в терминале напиши две команды (каждая Enter):

        cd путь\к\папке\katalog-uslug.pro

   (подставь свой путь, где README.md — можно перетащить папку в окно терминала)

        npm run neon:paste

   Если написало "Готово" — строка уже записана в worker\.dev.vars

5) Запуск сайта API на ПК:

        npm run worker:dev
